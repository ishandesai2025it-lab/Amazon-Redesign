# Amazon-Redesign
This is our 2nd semester EEL project where using figma we have to re-design an E-commerce website increasing its functionality and usability over all a better UI AND UX 


FIGMA prototype:https://www.figma.com/proto/myKn8zR4go4DQNF0HEzu8Q/EEL-2-PBL?node-id=141-1423&p=f&t=kMs71iJewcCiufMH-1&scaling=scale-down&content-scaling=fixed&page-id=0%3A1&starting-point-node-id=141%3A1423


Features:

  Minimalist Redesign** — Clean, modern interface with a clutter-free experience
  
  Less Product Clutter** — Better organization for faster product discovery
  
  Simplified Checkout** — Quick, smooth, and hassle-free payments
  
  Enhanced User Experience** — Intuitive navigation with improved usability
  
  Focused Shopping Journey** — Distraction-free browsing for better engagement
  
  Modern Visual Appeal** — Elegant design that feels premium and easy to use
  
  Faster Decision Making** — Streamlined layout helps users find products quickly
  
  Seamless Flow** — Optimized app journey from browsing to checkout
